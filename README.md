# Rune Clash

Tarayıcıda oynanan kart oyunu — TFT × hafıza oyunu.

**Oyna: https://artofdarkraven.github.io/rune-clash-play/**

Ortadaki kapalı rune kartlarını çevirip eşleştiriyorsun; bulduğun rune'un
elementindeki şampiyonların karşı takıma saldırıyor. Üstünde koleksiyon katmanı
var: şampiyonlar paketlerden çıkıyor, deste onlardan kuruluyor.

Rakip yapay zeka — rütbene göre zorlaşıyor. Gerçek PvP yok.

Bu depo yalnızca oynanabilir sürümü barındırıyor; kaynak kod ayrı.
